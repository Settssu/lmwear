PUBLICAÇÃO
1. Extrai o ZIP.
2. Na Vercel, abre o projeto LM WEAR e faz upload/deploy da pasta lmwear_publicacao (ou liga o projeto ao GitHub e envia os ficheiros para o repositório).
3. Depois do deploy, testa a página inicial, pesquisa, filtros, imagens e preços no telemóvel e computador.

SUPABASE
Se o projeto que está publicado continua a carregar os produtos da tabela public.products no Supabase, executa SUPABASE_CORRECOES_URGENTES.sql no SQL Editor do Supabase depois de enviares também as imagens para o alojamento do site. Se estiver a usar o catálogo local deste pacote, não precisas do SQL para ver os preços no site.
